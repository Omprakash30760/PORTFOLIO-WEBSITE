# Om Prakash Jena — Developer Portfolio

Personal developer portfolio website featuring a cinematic canvas scroll animation, interactive project showcases, verified credentials, and competitive programming profiles.

## 🌟 Key Features

- **Cinematic Canvas Scroll Animation**: 299-frame sequence synchronized to smooth scroll physics via HTML5 Canvas and Lenis.
- **Editorial Typography & Visual Style**: Luxury dark-palette design with warm cream accents (`#e7dcce`), gold highlights (`#cbb493`), and deep obsidian backdrop (`#030a10`).
- **Comprehensive Project Showcase**: Dedicated project hub with detailed case study pages for full-stack, data analytics, and machine learning projects.
- **Verified Credentials & Milestones**: AWS, Google Cloud, Cisco, Microsoft GitHub Copilot, VOIS/AICTE internship, Smart Interviews, Codeforces, HackerRank, CodeChef, and LeetCode.
- **Mobile Responsive & High Performance**: Optimized assets, responsive layouts, and accessible design.

---

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3, Modern JavaScript (ES6+)
- **Animation & Canvas**: HTML5 2D Canvas context, Lenis Smooth Scroll, Linear Interpolation (Lerp)
- **Design System**: Typography with Cinzel & Plus Jakarta Sans, custom CSS grid/flexbox layouts
- **Deployment**: Static hosting compatible with Vercel, Netlify, and GitHub Pages
