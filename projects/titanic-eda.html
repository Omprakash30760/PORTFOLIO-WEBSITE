1. PROJECT OVERVIEW

The Titanic Exploratory Data Analysis & Data Cleaning project is an exhaustive forensic investigation into raw tabular data hygiene, missing-value imputation strategies, and demographic survival correlations. By focusing squarely on data quality before any machine learning modeling is attempted, this study demonstrates how foundational data wrangling dictates analytical integrity.

2. PROBLEM STATEMENT

Real-world data is inherently imperfect. The raw Titanic passenger manifest suffers from substantial missingness: approximately 20% of passenger ages are absent, over 77% of cabin assignments are unrecorded, and categorical fields have missing ports of embarkation. Applying crude blanket imputations (like replacing all missing ages with the dataset mean) introduces statistical bias and corrupts downstream modeling.

3. PROJECT OBJECTIVES

  • Systematic Missingness Audit Quantify missing values across every attribute and generate missingness heatmaps to ascertain whether data is Missing Completely at Random (MCAR) or Missing at Random (MAR).
  • Stratified Feature Imputation Extract social titles (Master, Miss, Mr, Mrs, Dr) from passenger names to impute missing ages via stratified median calculations rather than a single global mean.
  • Exploratory Demographic Synthesis Examine multivariate correlations between passenger class, sex, fare paid, family size, and survival rates.

4. KEY FEATURES

  • Name Title Extraction Engine Parsed regex strings from passenger names to cluster individuals into demographic categories, yielding highly accurate localized median age imputations.
  • Fare Outlier Treatment Identified heavily right-skewed ticket fares, evaluated logarithmic transformations, and winsorized extreme outliers to protect downstream models.
  • Socioeconomic Survival Disparities Quantified the profound survival gap: 1st class female passengers exhibited a 96.8% survival rate compared to 13.5% for 3rd class male passengers.

5. IMPLEMENTATION DETAILS

The pipeline was constructed in Python with Pandas, NumPy, Matplotlib, and Seaborn. String manipulation functions extracted passenger titles, cross-tabulations compared survival counts across categorical combinations, and pairplots mapped continuous variables against survival outcomes.

6. RESULTS & LEARNINGS

The project reinforced the principle that data preprocessing is the single most critical phase of applied data science. Key learnings included mastering stratified imputation techniques, handling high-cardinality missingness safely, and structuring reproducible exploratory data workflows.
