1. PROJECT OVERVIEW

The Student Wellness Hub is a full-stack digital mental wellness platform developed to promote self-guided mental health tracking and confidential counseling appointments within collegiate environments. Built with a responsive React.js and Material UI client and a Spring Boot backend, the platform bridges the gap between campus support resources and students.

2. PROBLEM STATEMENT

University students frequently face academic stress, burnout, and social isolation. However, seeking professional counseling is often hindered by friction: lack of anonymity, convoluted manual scheduling, missed notifications, and absence of personal longitudinal mood awareness tools. The objective was to engineer an intuitive, private application combining self-reflection telemetry with streamlined appointment scheduling.

3. PROJECT OBJECTIVES

  • Longitudinal Sentiment Telemetry Provide students with daily visual mood logging to recognize cyclical stress triggers and track emotional wellness trends over weeks and months.
  • Automated Conflict-Free Appointment Scheduling Construct a calendar engine preventing double bookings and allowing students to seamlessly secure confidential counseling slots.
  • Robust Database Normalization Architect a normalized relational database schema across 4+ tables to isolate student identities, counseling notes, and session logs.

4. KEY FEATURES

  • Daily Mood Journaling & Analytics Interactive mood rating sliders with categorized emotion tags and dynamic visual trend curves.
  • Counselor Availability Engine Displays real-time open slots, manages booking statuses (Pending, Confirmed, Completed), and allows confidential cancellation.
  • Empathetic Material UI Design System Customized theme utilizing calming midnight teal tones, accessible contrast levels, and responsive layouts across mobile and desktop.

5. IMPLEMENTATION DETAILS

The backend service was structured in Spring Boot using RESTful API principles. Entity relationships were mapped using Hibernate ORM across four core relational tables: Students, Counselors, Appointments, and MoodLogs. Service methods enforce transactional consistency, ensuring booking conflicts trigger immediate rollbacks before records are committed.

The frontend utilizes React.js and Material UI component libraries, customized with clean theme typography and custom emotion icons. Reusable hooks manage asynchronous API states for fetching real-time counselor rosters and rendering mood telemetry charts.

6. RESULTS & LEARNINGS

The application demonstrated practical full-stack integration between React and Spring Boot. Database normalization reduced redundant data across user and booking tables, improving query efficiency. Key learnings included designing user-empathetic interfaces, handling date-time serialization across time zones in REST APIs, and structuring relational database foreign key cascades.
