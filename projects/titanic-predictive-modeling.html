TITANIC PREDICTIVE MODELING

Developed predictive models using feature engineering, missing-value imputation, categorical encoding, and feature scaling. Evaluated Random Forest, Logistic Regression, Decision Tree, and KNN models using cross-validation.

1. PROJECT OVERVIEW

Titanic Predictive Modeling is an end-to-end supervised machine learning study engineered to predict passenger survival based on demographic, socioeconomic, and ticketing variables. By applying rigorous feature engineering, data imputation, categorical encoding, and feature scaling, the project benchmarks four foundational classification algorithms using stratified cross-validation.

2. PROBLEM STATEMENT

Tabular classification problems often suffer from algorithmic bias and overfitting when raw data contains unhandled missingness, high multicollinearity, and skewed distributions. The challenge was to construct a leak-free machine learning workflow that extracts meaningful predictive features while maintaining model generalizability across unseen test folds.

3. PROJECT OBJECTIVES

  • Domain-Grounded Feature Engineering Derive synthetic features such as family unit size, solo traveler status, and stratified social titles from raw passenger metadata.
  • Leak-Free Preprocessing Pipeline Encapsulate numerical scaling and one-hot encoding within Scikit-learn pipelines to prevent data leakage from validation folds into training sets.
  • Multi-Model Cross-Validation Benchmark Random Forest, Logistic Regression, Decision Tree, and K-Nearest Neighbors (KNN) using 5-fold stratified cross-validation to evaluate precision-recall tradeoffs.

4. KEY FEATURES

  • Random Forest Superiority Random Forest achieved the strongest generalization (84.6% accuracy, 0.884 ROC-AUC) due to ensemble averaging mitigating variance.
  • Feature Importance Extraction Extracted Gini importance scores identifying gender, ticket class, and fare tier as the primary survival determinants.
  • Confusion Matrix Error Analysis Decomposed false positives and false negatives to evaluate the operational risks of misclassifying marginal survival probabilities.

5. IMPLEMENTATION DETAILS

The modeling pipeline was developed using Python and Scikit-learn. Categorical features were converted via OneHotEncoder with handle_unknown='ignore', while continuous features were normalized with StandardScaler. Cross-validation was orchestrated using StratifiedKFold to preserve label distributions across splits. Performance metrics included accuracy, precision, recall, F1-score, and ROC-AUC curves.

6. RESULTS & LEARNINGS

The project provided deep practical grounding in supervised classification methodologies. Key takeaways included mastering the mechanics of ensemble decision trees versus linear boundary models, appreciating the indispensability of cross-validation to avoid false optimism, and using Scikit-learn pipelines for reproducible machine learning engineering.
